# ONLINE-PLAY-1 adversarial threat model and residual risks

This document is a **security contract**, not evidence that tests have passed.
PR-A is offline synthetic only. The original RELEASE-1 offline entrypoint
and no-publication policy remain unchanged.

| Surface | Abuse case | Containment/evidence |
| --- | --- | --- |
| HTTP ingress | SSRF, absolute URI, encoded slash, query/path confusion | `live_gateway_policy.admit_route` parses the raw path and exact method; rejects unknown routes and hop-by-hop/proxy headers before forwarding |
| Token | bridge sends synthetic or real token; upstream replies keyed by real token | token file gateway only, identity/role/scope verification, minimal synthetic-keyed response; independent no-token redaction |
| Live origin | DNS/proxy override, redirect, insecure TLS | compiled-in `https://lichess.org`, `trust_env=False`, `verify=True`, `allow_redirects=False`, literal endpoint reconstruction |
| API misuse | upgrade, chat, resign, abort, takeback, pool, rated, humans | deny-by-default GET/POST, fixed path/body rules, BOT challenge check in gateway and pinned-hook bridge |
| One-game lifetime | duplicate/reordered challenges, new gameStart on restart | durable SQLite challenge/game key plus signed nonce; accept spent before transmitting; no second game |
| Unauthorized move | illegal UCI, stale owner, draw offer, move retries after timeout | existing `MoveJournal` and `guarded_transport`, owner-epoch fencing, gateway `posts(game,ply)` one-shot; only offeringDraw=false |
| 429 / partial ACK | immediate retries or secondary game | account-wide persisted >=60s cooldown, UNKNOWN_ACK failure containment, no speculative POST |
| Stream protocol | malformed/oversized NDJSON, dropped keepalive, duplicate global stream | bounded incremental line processing, blank lines retained, one stream lock per type, source-bound `gameFull` |
| Namespace escape | bridge directly accesses Lichess or reads gateway token | separate Docker namespace/internal-only network, gateway-only secret mount and actual failed direct TCP negative probe |
| Host/resources | insufficient cgroup quota, linked/volatile journal, orphan worker | named host observer, separate persistent volume, PID1 supervisor and bounded drain, fail-closed unsigned/expired lease |
| Release promotion | synthetic CI PASS treated as authority | schemas, exact old release byte comparison, source policy all false, separate unapproved PR-B |

### Important remaining concerns and explicit blockers

The PR-A test keypair is generated by CI and intentionally **not** a
real-world trust anchor. Before any real-world operation, PR-B must pin and
independently review the true public key and approval channel. A signed
host receipt cannot replace actual inspection of the named host and the
actual runtime mounted secret/egress separation. An operator must review
GPL/AGPL network-use and publication requirements independently.

The test-only fake gateway uses a private local-session adapter. The
production `LiveGateway` never takes a caller-controlled URL. Tests that
exercise local HTTP are not proof of real CA/DNS/TLS behavior, so TLS host,
proxy, redirect, and 401/403 negatives are separately required and any
untested area is a **blocker**.

A receipt asserting no descendants is not itself proof; the Docker
supervisor and independent process inspection must cover the actual PID
namespace. Real first-game power loss and crashed network calls are
recovery-specific host hazards even when offline synthetic crash tests
pass. Never resend an uncertain move: obtain authoritative full-history
confirmation or suspend.

A blank heartbeat line is not stream EOF. A long-running account/event
stream and game stream must not monopolize the nonstream mutex. The
pinned bot may return `offeringDraw=false` on move POST: the gateway
permits precisely that value and rejects `true`.

**Claim cap:** only an independently replayed fake-server game is eligible
for `DRY_RUN_PASS`; successful PR code is not authorization, rating
evidence, a live-host qualification or a legal conclusion.
